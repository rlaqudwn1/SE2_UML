## 확인한 기준 자료

사용자가 제공한 소프트웨어 요구사항 명세서 v0.3(2026-09-23 변경 이력), 기능·데이터·비기능·비즈니스 규칙·비즈니스 요구사항·수락 기준·외부 인터페이스·용어 사전 CSV 8개를 대조했다. PDF 표의 숨겨진 열은 CSV로 보완했다. 원본은 Downloads의 ExportBlock 폴더에 있으며 저장소에는 복사하지 않았다.

[GitHub 저장소](https://github.com/rlaqudwn1/SE2_UML)의 원격 main은 `88daeb4`, dev는 `25e72b7`, 공통 모델 브랜치는 `f84fa1a`인 상태를 확인했다. dev 및 공통 모델 브랜치의 파일 목록에는 구현 소스가 없었다. 현재 개인 작업 브랜치의 기존 변경을 유지하며 모델 계약을 수정했다. 다른 개인 기능 브랜치의 구현을 병합한 결과는 아니다.

## 미결정 및 해석

- PDF는 흑백 + 최소 4색, CSV 수락 기준은 흑백 포함 최소 4색으로 차이가 있다. 더 넓은 흑백 + 4색을 기본 팔레트로 제안했다.
- FR-2·FR-4·FR-8 및 일부 AC는 원문에서 검토 중이다. FR-9~13은 상태/AC가 비어 있다. 모델에 표현하되 확정 상태로 바꾸지 않는다.
- 스냅 기준점/거리, 실시간 동기화 시점, 최종 플랫폼, 논문 정리 기능은 고객 확인 대상이다.
- FR-3의 'GUI 이동을 코드에도 반영'과 'Mermaid 자체 문법만'을 동시에 충족하는 좌표 표현은 아직 합의되지 않았다. 배치 JSON 보존만으로 AC-3 완료를 주장하지 않는다.
- undo 이력의 파일 저장 여부는 원문에 없으므로 세션 한정으로 제안했다. UI 구현 전에 팀 합의가 필요하다.
- 전체 Mermaid 구문 범위는 이번 모델만으로 완성되지 않는다. note/fragment 등의 미지원 구문은 손실 없이 진단하고 반영을 중단한다.

문법 참고: [Mermaid 클래스](https://mermaid.js.org/syntax/classDiagram.html), [Mermaid 시퀀스](https://mermaid.js.org/syntax/sequenceDiagram.html). `*.mmd` 예시는 이 표준 문법을 따르도록 작성했으나 아직 실제 Mermaid 엔진 파싱/렌더링 검증은 하지 않았다.

객체 표기는 필드 설명용입니다. JSON 저장 형식이나 serializer 계약을 새로 정의하는 것은 아닙니다. 예시 진단 code 문자열도 표준으로 확정된 값이 아닙니다.



04 · 출력에서 약속하는 것
영역 · Bounds
participantBounds와 rowBounds는 ID별 x, y, width, height입니다. canvasBounds는 여백을 포함한 전체 영역입니다.
연결점 · Point
rowAnchors는 행의 참여자 참조 순서를 유지합니다. x는 참여자 중심이며, 선·화살표의 UML 의미는 렌더러가 해석합니다.
진단 · Diagnostic
선호 좌표 조정은 WARNING, 불가능한 고정 좌표는 ERROR입니다. hasErrors()가 true인 좌표는 정상 배치로 사용하지 않습니다.
